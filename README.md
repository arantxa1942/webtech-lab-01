## Interactive features (Lab 2)

- **Live filter** In the "Books read" section, type in the search box to filter books by title, author, or genre. Clear the box to see all books again.
- **Add / remove books** Use the "Add book" form to add a new book with title, author, and genre. Click "Remove" on any book card to delete it, including ones that were just added.
- **Contact form validation** In the "Contact" section, i shows a message error when submitting a empty field or an invalid email. Fix the field and the error disappears automatically.
- **Light/dark mode toggle** Click "Light mode" in the top-right of the header to switch the whole site's color theme. Click again to switch back.
