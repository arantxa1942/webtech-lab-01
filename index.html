Low Level Programming: Simulation of celestial bodies

June 25, 2026

Built a C++ library that simulates a simplified planetary system with a central star, an orbiting gas giant, and a field of asteroids. Using Newtonian gravity and the Euler method for numerical integration. The library handles inelastic collisions and escape velocity, I then made the library callable from Python using SWIG. On top of that, I wrote a Python program using matplotlib to animate the simulation in real time, showing the star, planet and asteroids moving and interacting as the system evolves.

Low Level Programming: Urujo Puzzle Solver

May 28, 2026

Built a C++ program that solves Urjo, a logic puzzle where you fill a grid with two symbols following a few simple rules. The program reads puzzles from a file, checks whether a move is valid, and automatically finds a solution using a search algorithm. It also has an interactive mode where you can play the puzzle yourself from the terminal.
